# V38 FIX35 — padrón público, América 35+ y publicaciones

## Qué cambia

- Web/PWA: `38-35`.
- La vista Jugadores ya no queda limitada a 200 tarjetas. Muestra todos los nombres deportivos que la fuente pública permite reconstruir desde cédulas, con filtros por categoría y equipo.
- Se listan las cédulas públicas escaneadas y cada una enlaza a AdminFut.
- Club América de Veteranos 35+ usa `assets/branding/america-veteranos-35.svg` en la tarjeta del equipo.
- `publicaciones/latest/` contiene PNG de tablas, próxima jornada, resumen de tablas, resumen de jornada y comunicado América 35+.
- GitHub Actions hace sincronización completa al publicar cambios en `main`, auditoría amplia de cédulas públicas y generación de imágenes.
- Viernes se generan los materiales sociales con los datos disponibles.

## Cobertura pública

La fuente oficial es `https://www.juventinorosasliga.com/` y siempre prevalece sobre el snapshot.

La auditoría FIX35 examina cédulas públicas del rango 1–650 y conserva únicamente información deportiva visible. No recopila ni publica CURP, INE, domicilio ni imágenes de documentos.

Un total del dashboard puede ser mayor que los nombres visibles en cédulas si existe un jugador registrado que todavía no aparece en una cédula pública. En ese caso FIX35 muestra la diferencia en vez de inventar el nombre.

Veteranos 35+ actualmente aparece en la fuente pública con 10 equipos, 0 partidos jugados, 0 pendientes y 0 jugadores, por lo que no existen cédulas públicas actuales desde las cuales recuperar nombres.

## WhatsApp automático

El repositorio NO contiene números telefónicos ni tokens. El envío automático se activa únicamente si el propietario configura estos GitHub Actions Secrets:

- `WHATSAPP_TOKEN`
- `WHATSAPP_PHONE_NUMBER_ID`
- `WHATSAPP_TO`
- opcional `META_GRAPH_VERSION`

Nunca pegues esos tokens en archivos públicos ni en el chat. Configúralos desde GitHub > Settings > Secrets and variables > Actions.

Cuando están configurados, el workflow puede enviar `resumen-jornada.png` y `resumen-tablas.png` en la ejecución social del viernes o mediante `workflow_dispatch` con `send_social=true`.

## Facebook automático

Para publicar directamente con Meta se requieren:

- `FACEBOOK_PAGE_ID`
- `FACEBOOK_PAGE_TOKEN`
- opcional `META_GRAPH_VERSION`

Sin esos secretos el workflow genera las imágenes pero omite la publicación, sin fallar.

Además, la cuenta Metricool conectada en ChatGPT existe, pero al crear FIX35 no mostraba ninguna red social conectada en `networksData`. Cuando se conecte la página de Facebook a Metricool, ChatGPT podrá programar/publicar desde esa integración con autorización del usuario.

## Canva

Se creó un diseño editable de 9 páginas en Canva: 4 tablas, 4 próximas jornadas y 1 comunicado de América Veteranos 35+.

Canva Bulk Create/Autofill exige un plan Canva Enterprise. FIX35 no depende de esa función: las imágenes automáticas se generan en GitHub Actions y el diseño Canva queda como plantilla editable para ajustes manuales.
