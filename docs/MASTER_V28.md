# MASTER V28 — acciones funcionales y fichas rápidas

## Qué corrige
1. Cualquier equipo importante que aparezca como texto/botón ahora puede abrir una ficha rápida.
2. El bloque de bracket ya no muestra campeón adelantado: se cambia a “Por definir / Campeón por definir”.
3. La pastilla “5 categorías” ahora abre selector funcional de categorías.
4. La pastilla “MASTER V14…” se cambia por un texto real de la liga y abre información funcional.
5. Botones/sedes como “Campo 1 · Unidad Deportiva Sur” ahora abren descripción y enlace a Google Maps.
6. “Pulso de la afición” se vuelve de un voto por dispositivo usando localStorage.
7. Los renglones de goleadores se separan visualmente y se vuelven clicables para abrir ficha del jugador.
8. El indicador “73'” abre estado del partido / acceso a Match Center.

## Nota importante
Sin backend no existe voto realmente global; esta versión guarda el voto por dispositivo.
Con Supabase o base de datos después, se puede convertir a voto global en tiempo real.
