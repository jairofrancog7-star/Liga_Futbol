# 7 referencias de balón 3D para Liga Juventino Rosas

1. TechTronixx / 3D-Ball-3js
https://github.com/TechTronixx/3D-Ball-3js
Referencia directa para balón grande, rotación interactiva, GSAP y control de cámara.

2. jeromeetienne / threex.sportballs
https://github.com/jeromeetienne/threex.sportballs
Modelo de football para Three.js. Licencia MIT.

3. MohammadMarwan2005 / football-simulation
https://github.com/MohammadMarwan2005/football-simulation
Física 3D: gravedad, drag, efecto Magnus, colisiones, rodamiento y disparo.

4. xbeat / AI-3DSoccer
https://github.com/xbeat/AI-3DSoccer
Juego de fútbol 3D en JavaScript/Three.js. Licencia MIT.

5. jonymusky / 2026-world-cup-ai-battle
https://github.com/jonymusky/2026-world-cup-ai-battle
Incluye balón de fútbol 3D interactivo con Three.js. Licencia MIT.

6. makerjackie / the-other-half
https://github.com/makerjackie/the-other-half
Experiencia futbolística 3D con cámara y controles táctiles/escritorio. Código MIT.

7. suzubu / threejs-physics-demo
https://github.com/suzubu/threejs-physics-demo
Three.js + Rapier, movimiento físico e influencia del mouse. Licencia MIT.

V36 no pega siete proyectos completos. Usa una implementación propia con Three.js:
balón grande, 12 pentágonos 3D, luces, halos, drag táctil, rotación y patada al tocar.
