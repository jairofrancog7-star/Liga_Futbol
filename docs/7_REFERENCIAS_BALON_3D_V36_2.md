# 7 referencias estudiadas para los balones 3D de Liga Juventino Rosas

MASTER V36.2 no pega siete proyectos completos. Toma ideas de interacción, cámara, física y presentación y las reimplementa en una capa propia.

1. TechTronixx / 3D-Ball-3js
   https://github.com/TechTronixx/3D-Ball-3js
   Referencia visual para balón 3D grande y control de cámara/rotación.

2. jeromeetienne / threex.sportballs
   https://github.com/jeromeetienne/threex.sportballs
   Extensión Three.js para balones deportivos; el repositorio publica licencia MIT.

3. MohammadMarwan2005 / football-simulation
   https://github.com/MohammadMarwan2005/football-simulation
   Simulación de pelota con gravedad, drag, efecto Magnus, colisiones y rodamiento.

4. in-c0 / soccer-tactics-studio
   https://github.com/in-c0/soccer-tactics-studio
   Three.js + interacción, cámaras y escenas de fútbol; licencia MIT.

5. mmaquer2 / VirtualSoccerField
   https://github.com/mmaquer2/VirtualSoccerField
   Campo 3D y objetos arrastrables con Three.js.

6. collidingScopes / keep-ups
   https://github.com/collidingScopes/keep-ups
   Juego 3D en navegador con pelota y movimiento interactivo.

7. acherm / fifacher
   https://github.com/acherm/fifacher
   Presentación futbolística en Three.js, escenas procedurales y controles para teléfono/escritorio.

## Decisión V36.2

- Balón superior: plata/negro + verde/cian, flotante.
- Balón inferior: grafito/plata + dorado/verde, con partículas y movimiento tipo rodamiento.
- Ambos son interactivos.
- Se evita usar un modelo de Sketchfab sin verificar su licencia concreta.
- Three.js se usa como motor y el código de integración V36.2 es propio.
