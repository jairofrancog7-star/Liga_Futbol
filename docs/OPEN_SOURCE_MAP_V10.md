## Regla

Antes de copiar cualquier archivo concreto:
1. verificar el `LICENSE` del commit/revisión usada;
2. conservar avisos obligatorios;
3. documentar el origen en este archivo;
4. preferir portar lógica/patrón al stack principal en vez de mezclar frameworks.
